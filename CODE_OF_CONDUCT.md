# Código de conducta

## Nuestro compromiso

Queremos que este proyecto sea un espacio abierto, respetuoso y seguro para
todas las personas, sin importar su experiencia, identidad, origen, situación
laboral o punto de vista.

## Comportamiento esperado

- Tratá a las demás personas con respeto.
- Críticas técnicas concretas, sin ataques personales.
- Escuchá y respondé de buena fe.
- Reconocé cuando te equivocás y corregí.
- Cuidá la privacidad de terceros: no publiques expedientes, nombres, causas ni
  datos de clientes.
- Ayudá a que quien recién llega pueda participar.

## Comportamiento inaceptable

- Insultos, amenazas, acoso o discriminación.
- Comentarios sexuales o atención no deseada.
- Publicar información privada de otras personas sin permiso.
- Subir expedientes reales o datos de clientes.
- Interrumpir discusiones de forma reiterada o bad faith.
- Cualquier conducta que razonablemente se considere inapropiada en un espacio
  profesional.

## Alcance

Este código aplica a issues, pull requests, discusiones, revisiones de código,
chats del proyecto y cualquier espacio donde alguien represente al proyecto.

## Aplicación

Si presenciás o sufrís una conducta inaceptable, escribí a
`francopuszkarsky@gmail.com` con el asunto `CONDUCTA separador-expedientes`.

Los reportes se tratan con confidencialidad. Quien mantiene el proyecto puede
pedir una aclaración, advertir, cerrar una discusión, rechazar una contribución
o bloquear a una persona según la gravedad y la reiteración.

No se tomarán represalias contra quien reporte de buena fe.
